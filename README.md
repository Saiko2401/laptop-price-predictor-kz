# 💻 LaptopFairPrice KZ: ML-оценка стоимости б/у ноутбуков

Интеллектуальная система оценки рыночной стоимости и ликвидности бывших в употреблении ноутбуков на вторичном рынке Казахстана на основе данных площадки OLX.kz.

## 📌 Описание проекта
Вторичный C2C-рынок электроники характеризуется выраженной ценовой асимметрией: продавцы часто завышают цены из-за субъективной оценки или закладывают нереалистичный торг, из-за чего объявления простаивают неделями.

Данный проект реализует сквозной ML-пайплайн (End-to-End):
1. **Сбор и обработка данных:** сбор объявлений с OLX по городам РК.
2. **Feature Engineering:** извлечение брендов, линеек, CPU/GPU поколений, объемов памяти и физического состояния с помощью регулярных выражений.
3. **ML-моделирование:** сравнительный анализ регрессионных моделей с оценкой по метрикам MAE, RMSE, R², MAPE и Hit Rate @ 15%.
4. **Интерактивный Deployment:** развертывание веб-приложения на базе Streamlit для моментального расчета справедливой рыночной цены и коридора торга.


### Системные требования:
* Python 3.10+ (протестировано на Python 3.10, 3.11, 3.12)


## 📊 Результаты моделей

В ходе экспериментов сравнивались три модели (целевая переменная обучалась в логарифмической шкале $\log(1+y)$):

| Модель | MAE (₸) | RMSE (₸) | R² | MAPE (%) | Hit Rate @ 15% |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 1. Baseline: Ridge Regression | 94 667 ₸ | 141 566 ₸ | 0.430 | 37.3% | 32.5% |
| 2. Random Forest Regressor | 89 190 ₸ | 137 142 ₸ | 0.465 | 35.6% | 36.8% |
| **3. Gradient Boosting Regressor** | **85 348 ₸** | **131 461 ₸** | **0.509** | **34.2%** | **39.1%** |

**Финальная модель:** Gradient Boosting Regressor продемонстрировал наилучшую обобщающую способность, снизив среднюю абсолютную ошибку на ~9 300 ₸ по сравнению с базовой линейной моделью.


## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/](https://github.com/)<ваш-логин>/laptop-price-predictor-kz.git
cd laptop-price-predictor-kz
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск веб-приложения
```bash
streamlit run app.py
```
Приложение откроется локально по адресу `http://localhost:8501`.
